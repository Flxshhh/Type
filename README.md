# Слепая печать

Клавиатурный тренажёр для слепой печати на MacBook. Без таймера: бесконечный поток слов.

## Возможности

- Остановка на ошибке: дальше не пойдёшь, пока не нажмёшь верную клавишу.
- Подсказка пальцев: клавиши раскрашены по пальцам, нужная подсвечена, внизу рисунок рук с активным пальцем.
- Скорость (текущая и средняя, зн/мин и WPM), точность с первой попытки, счётчик ошибок, время практики.
- Уровни: основной ряд → + верхний ряд → все буквы. Русская и английская раскладки.
- Статистика слабых клавиш: слова с проблемными буквами выпадают чаще.

## Запуск

Открой `index.html` в браузере. Можно включить GitHub Pages (Settings → Pages → ветка `main`).

Раскладка на Mac переключается через `Ctrl + Пробел` или `Fn`.
